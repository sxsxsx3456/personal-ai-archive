# Personal AI Archive

A portable, Markdown-first personal knowledge base for use across AI assistants and devices.

> **Privacy:** This repository is public. Do not add passwords, API keys, personal identification numbers, private contact details, health/financial secrets, confidential employer/customer information, or private conversation dumps.

## Structure
- `identity/` — stable profile and goals
- `workflow/` — work practices, tools, communication, prioritization
- `memory/` — durable preferences, decisions, lessons learned
- `skills/` — skills and learning plans
- `archive/` — completed projects and historical records

## Operating rules
1. Treat `AI-READONLY` files as read-only context unless the owner explicitly approves an edit.
2. Treat `AI-UPDATE-CANDIDATE` files as append/update candidates, not permission for autonomous publication.
3. Never infer facts to fill placeholders. Mark unknowns as `待确认`.
4. Prefer concise, dated, source-attributed entries.
5. Propose changes as a diff or pull request; do not overwrite existing content blindly.
6. Keep sensitive/private material outside this public repository.

See [ai-integration.md](ai-integration.md) and [SECURITY.md](SECURITY.md).
